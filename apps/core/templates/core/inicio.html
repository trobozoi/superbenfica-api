Como começar

  1. Faça login Em POST /api/auth/token/ com e-mail e senha. Os usuários de exemplo vêm da carga inicial.
  2. Autorize no Swagger Clique em Authorize e cole o token access, sem o prefixo "Bearer".
  3. Teste os endpoints Use Try it out. O token expira em 15 minutos; renove em /api/auth/token/refresh/. Ao exceder o limite de requisições, a API responde 429 com o cabeçalho Retry-After.
